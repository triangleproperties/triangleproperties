# Triangle Properties & Constructions

Client-facing website for **Triangle Properties & Constructions** (Phase 1 MVP).

## Features
- **Modern UI**: Dark/Light mode toggle, Tailwind CSS, Glassmorphism, smooth animations.
- **Pages**: Home, About, Services, Properties (Listing + Search/Filter + Detail Modal), Construction (Cost Estimator), Joint Venture (Landowner Proposal Form), Gallery, Contact.
- **Interactive Tools**:
  - Property Keyword & Category Filter
  - Construction Cost Estimator per Sq.Ft
  - Client Inquiry Form with Firestore / Local Storage fallback
- **SEO Ready**: Meta tags, JSON-LD Schema, `sitemap.xml`, and `robots.txt`.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Tailwind CSS
- Firebase Firestore (Client Inquiry Handler)
